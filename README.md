# TAB — Telegram Agents Bridge

Windows-приложение для работы с локальными CLI-агентами **Codex, Claude Code и OMP** через Telegram. Агенты выполняют задачи на вашем ПК; сообщения и файлы доступны в личном чате с ботом.

Стек: Rust, Tauri 2, React, TypeScript. Проект в разработке.

## Что установить

- **Windows 10/11 x64** и Git.
- **Node.js 22.12+** с npm.
- **Rust stable** через rustup, toolchain `stable-x86_64-pc-windows-msvc`.
- **Visual Studio Build Tools 2022**: компонент «Разработка классических приложений на C++» с MSVC и Windows SDK.
- **Microsoft Edge WebView2 Runtime**.

После установки откройте новое окно PowerShell. Для работы с агентами отдельно установите нужные CLI и авторизуйтесь в них.

## Скачать и запустить

В PowerShell:

```powershell
git clone https://github.com/rom4ukqq/tab.git
cd tab
npm.cmd --prefix apps/desktop ci
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\dev.ps1
```

Последняя команда запускает приложение в режиме разработки. При первом запуске Cargo скачает и скомпилирует Rust-зависимости.

## Собрать EXE и установщик

Из корня репозитория, после установки npm-зависимостей из предыдущего шага:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\dev.ps1 -Build
```

Результат:

- `target\release\TAB.exe` — приложение; для запуска нужен WebView2 Runtime.
- `target\release\bundle\nsis\` — установщик `*-setup.exe` для текущего пользователя. При необходимости скачивает WebView2.

Скрипт собирает и интерфейс, и Rust-приложение. Локальная папка `.tools` не нужна: при её отсутствии используется Rust из системного `PATH`.

## Подключить Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен. Узнайте свой **числовой User ID** через [@userinfobot](https://t.me/userinfobot).
2. В TAB откройте **Агенты → Найти агенты** и включите нужные CLI. Для Claude/OMP примите локальное предупреждение о sandbox.
3. В разделе **Telegram** укажите токен и User ID, сохраните настройки и нажмите **Подключить**. На ПК появится одноразовый PIN на 5 минут.
4. Откройте своего бота, отправьте `/start`, затем PIN с экрана TAB. Выберите сессию и агента, отправьте задачу. Путь к проекту укажите агенту в сообщении.

Один бот должен использоваться только одним запущенным мостом; другие poller/webhook нужно отключить. ПК и TAB должны оставаться запущенными. Закрытие окна сворачивает приложение в трей; полный выход — через меню трея.

## Команды и файлы

| Команда | Действие |
| --- | --- |
| `/sessions` | Выбрать или создать сессию |
| `/stop` | Остановить задачи выбранной сессии |
| `/lock` | Закрыть удалённый доступ и остановить задачи |
| `/files` | Выбрать файлы из `.tab/outbox` для отправки в Telegram |
| `/help` | Полная справка |

Вложения отправляйте боту, затем нажмите **Отправить вложения**. Для получения результата попросите агента сохранить файл в `.tab/outbox` внутри его рабочей папки и вызовите `/files`.

Настройки и данные: `%LOCALAPPDATA%\TAB`; токен хранится в Windows Credential Manager. После перезапуска доступ нужно подтвердить новым PIN. Разрешения на действия зависят от CLI; текстовое «да» не заменяет кнопку подтверждения.
