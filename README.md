# TAB — Telegram Agents Bridge

Windows-приложение для работы с локальными CLI-агентами **Codex, Claude Code и OMP** через Telegram. Агенты выполняют задачи на вашем ПК; сообщения и файлы доступны в личном чате с ботом.

Стек: Rust, Tauri 2, React, TypeScript. Проект в разработке.

## Что установить

- **Windows 10/11 x64** и Git.
- **Node.js 22.12+** с npm.
- **Rust stable** через rustup, toolchain `stable-x86_64-pc-windows-msvc`.
- **Visual Studio Build Tools 2022**: компонент «Разработка классических приложений на C++» с MSVC и Windows SDK.
- **Microsoft Edge WebView2 Runtime**.

После установки откройте новое окно PowerShell. Для работы с агентами отдельно установите нужные CLI и авторизуйтесь в них.

## Скачать и запустить

В PowerShell:

```powershell
git clone https://github.com/rom4ukqq/tab.git
cd tab
npm.cmd --prefix apps/desktop ci
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\dev.ps1
```

Последняя команда запускает приложение в режиме разработки. При первом запуске Cargo скачает и скомпилирует Rust-зависимости.

## Собрать EXE и установщик

Из корня репозитория, после установки npm-зависимостей из предыдущего шага:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\dev.ps1 -Build
```

Результат:

- `target\release\TAB.exe` — приложение; для запуска нужен WebView2 Runtime.
- `target\release\bundle\nsis\` — установщик `*-setup.exe` для текущего пользователя. При необходимости скачивает WebView2.

Скрипт собирает и интерфейс, и Rust-приложение. Локальная папка `.tools` не нужна: при её отсутствии используется Rust из системного `PATH`.

## Подключить Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен. Узнайте свой **числовой User ID** через [@userinfobot](https://t.me/userinfobot).
2. В TAB откройте **Агенты → Найти агенты** и включите нужные CLI. Для Claude/OMP примите локальное предупреждение о sandbox.
3. В разделе **Telegram** укажите токен и User ID, сохраните настройки и нажмите **Подключить**. На ПК появится одноразовый PIN на 5 минут.
4. Откройте своего бота, отправьте `/start`, затем PIN с экрана TAB. Выберите сессию и агента, отправьте задачу. Путь к проекту укажите агенту в сообщении.

Один бот должен использоваться только одним запущенным мостом; другие poller/webhook нужно отключить. ПК и TAB должны оставаться запущенными. Закрытие окна сворачивает приложение в трей; полный выход — через меню трея.

## Команды и файлы

| Команда | Действие |
| --- | --- |
| `/sessions` | Выбрать или создать сессию |
| `/stop` | Остановить задачи выбранной сессии |
| `/lock` | Закрыть удалённый доступ и остановить задачи |
| `/status`, `/limits` | Effort, доступ, остаток контекста и лимитов по последним данным CLI |
| `/effort high` | Установить effort для следующих задач сессии; `/effort default` — настройки CLI |
| `/access full`, `/access normal` | Полный доступ без обычных подтверждений или обычный режим со следующей задачи |
| `/queue` | Показать очередь, отменить задачу или нажать Push для ожидающего текста |
| `/push ТЕКСТ` | Передать уточнение работающему Codex/OMP |
| `/files` | Выбрать файлы из `.tab/outbox` для отправки в Telegram |
| `/help` | Полная справка |

Вложения отправляйте боту, затем нажмите **Отправить вложения**. Для получения результата попросите агента сохранить файл в `.tab/outbox` внутри его рабочей папки и вызовите `/files`.

Можно отправлять сообщения подряд: они выполняются по очереди. Push переносит ожидающий текст в текущую задачу только после подтверждения CLI. При отказе текст остаётся в очереди; при неизвестном результате автоматического повтора нет. Push вложений и Claude не поддерживается.

В `/queue` у ожидающих сообщений доступны **Изменить**, **↑ Выше** и **Объединить со следующим**. Изменение принимает следующий текст и сохраняет вложения; `/cancel_edit` отменяет ввод. Объединение сохраняет оба текста и вложения в первой задаче (общие лимиты: 80000 байт текста, 10 вложений). Порядок очереди определяет реальный порядок запуска. Уже запускающиеся и работающие задачи не редактируются.

Отдельная карточка статуса обновляется по событиям CLI: запуск, размышление, чтение, редактирование, выполнение инструмента, ожидание подтверждения/ответа и завершение. В ней есть остановка конкретной задачи и обновление статуса. Время обновляется при событиях и по кнопке или `/status`, без секундного спама в чат.

После завершения бот присылает карточку результата: состояние, длительность, короткую выдержку из ответа и файлы, изменения которых подтверждены структурированными событиями CLI. Это не полный файловый аудит: изменения через произвольные shell-команды могут отсутствовать. **Скачать файлы результата** открывает список `.tab/outbox` с кнопками скачивания; папка может содержать результаты предыдущих задач. Полный ответ агента остаётся отдельным моноширинным сообщением.

Поддерживаются фото, документы, голосовые, аудио, видео, видеокружки и анимации (до 20 MiB на файл, до 10 вложений). Текст после вложений добавляется к их подписи. Голосовые передаются агенту аудиофайлом, а не готовой расшифровкой: для распознавания агенту нужны соответствующие инструменты.

Effort и доступ задаются отдельно для текущей сессии и не меняют уже запущенную задачу. Full использует Codex `danger-full-access`/`never`, Claude `bypassPermissions`, OMP `yolo`; ограничения администратора/провайдера сохраняются. Настройки сбрасываются с закрытием сессии или перезапуском TAB. Остатки контекста и лимитов поступают из CLI Codex/OMP; отсутствующие данные отображаются как «нет данных», а не как 0%. Вне работающей задачи `/status` показывает последний полученный снимок.

Протоколы: [Codex app-server](https://learn.chatgpt.com/docs/app-server), [Claude CLI](https://code.claude.com/docs/en/cli-reference), [OMP CLI](https://github.com/can1357/oh-my-pi/blob/main/docs/cli-reference.md), [OMP RPC](https://github.com/can1357/oh-my-pi/blob/main/docs/rpc.md).

Настройки и данные: `%LOCALAPPDATA%\TAB`; токен хранится в Windows Credential Manager. После перезапуска доступ нужно подтвердить новым PIN. Разрешения на действия зависят от CLI; текстовое «да» не заменяет кнопку подтверждения.
