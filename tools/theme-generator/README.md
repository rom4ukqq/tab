# TAB Theme Generator

Откройте `index.html` в актуальном Edge или Chrome с WebCodecs. Сервер, Python и TAB для запуска не нужны. Сохраняйте вместе `index.html`, `theme-data.js`, `video-import.js` и папку `vendor`.

Импорт использует последовательное декодирование Mediabunny/WebCodecs, без покадровых перемоток и без пропуска кадров из-за скорости компьютера. Сохранены 24 отсчёта в секунду, сетка до 90×68 ячеек и прежняя формула яркости. Прогресс показывает затраченное время; отмена освобождает декодер и сохраняет предыдущую тему. Неподдерживаемый кодек выдаёт ошибку, а не незаметно снижает качество.

Mediabunny 1.63.0 поставляется локально под MPL-2.0: см. `vendor/README.md` и `vendor/LICENSE-mediabunny.txt`.

Выберите видео, настройте ASCII и нажмите «Экспорт темы (.zip)». Обработка локальная. Архив содержит данные ячеек, настройки, SHA-256 и превью; исходное видео не включается.

В TAB откройте Settings → Import theme и выберите экспортированный `.tab-theme.zip`. Тема добавится в список фонов и сохранится в локальном хранилище WebView приложения. Встроенный фон только Matrix; старые Saveli/pr0n больше не поставляются внутри приложения. Архивы прежнего генератора также поддерживаются. Хранилище ограничено 16 темами / 256 МиБ, одна тема — 64 МиБ распакованных кадров.

Генератор поставляется отдельно в папке `theme-generator` рядом с TAB.

Разработка: после изменения `frames.json` или `frames.bin.gz` выполните `python pack_data.py`. При обычном использовании Python не нужен.
